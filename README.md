# Лабиринт П

Сайт проекта «Лабиринт П»: знания о психике и практическое обучение.
Главная страница посвящена тренингу противодействия психологическому давлению и манипуляциям.

## Локальный запуск

Сайт статический, для просмотра сборка не требуется:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте <http://127.0.0.1:8765/v2/>.

## Структура

- `v2/` — страницы сайта, стили, JavaScript и все локальные ресурсы.
- `v2/assets/` — изображения, видео, шрифты и 3D-модели.
- `v2/vendor/` — используемые библиотеки и их лицензии.
- `tools/` — подготовка CSS/JavaScript и оптимизация шрифтов.
- `tests/` — проверки интерфейса, прокрутки и производительности на Playwright.
- `docs/` — заметки о дизайне, изменениях и проверках.

## Обновление ресурсов

После редактирования исходных стилей и классических скриптов выполните:

```sh
python3 tools/build-landing-assets.py
```

Для обновления веб-шрифтов нужен пакет `fonttools[woff]`:

```sh
python3 tools/optimize-fonts.py
```

## Проверки

При работающем локальном сервере установите зависимости и запустите проверку:

```sh
npm install --no-save playwright sharp
node tests/design-smoke.cjs
```

Тесты рассчитаны на Google Chrome в стандартном каталоге macOS; основной smoke-тест
также принимает путь к браузеру через `CHROME_PATH`. Остальные проверки находятся
в отдельных файлах `tests/*.cjs`.

## Размещение

Для размещения сайта загрузите содержимое `v2/` в корневой каталог статического
хостинга или сохраните этот каталог и открывайте сайт по адресу `/v2/`.
Серверная сборка не требуется.

Лицензии сторонних шрифтов, моделей и библиотек сохранены рядом с ресурсами.
