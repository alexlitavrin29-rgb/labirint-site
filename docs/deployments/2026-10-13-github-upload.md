# Публикация исходников на GitHub

Репозиторий: https://github.com/alexlitavrin29-rgb/labirint-site

Публикуется текущая версия сайта из `v2/` вместе с ресурсами, инструментами,
тестами и технической документацией. Отдельный каталог `literature_search/`
не относится к сайту и исключён из репозитория.

Перед загрузкой проверены синтаксис 12 собственных JavaScript-файлов,
наличие локальных ресурсов, указанных в HTML, и допустимые размеры файлов.
Полный набор Playwright-проверок: 20 тестов, 18 прошли, 2 завершились ошибкой.

В существующих тестах обнаружены ограничения текущей версии:

- `mobile-toolbar-resize.cjs`: после смены ориентации с портретной на альбомную
  и обратно сцена `pitch-story` не восстанавливается. Повторный запуск
  воспроизводит то же падение проверки.
- `performance-budget.cjs`: в одном из трёх прогонов при замедлении процессора
  в четыре раза обнаружена одна задержка кадра больше 100 мс при прокрутке.
  Два других прогона прошли весь бюджет; LCP всех трёх прогонов меньше 2,5 с,
  CLS равен нулю.

При переносе на GitHub код и поведение сайта не изменялись. Результаты тестов
не являются заявлением, что весь набор проверок проходит.
