# Строка от скролла и локальное отталкивание частиц

Уточнение пользователя: в начале сцены пусто; крупная фраза выходит из-за правого края и проходит влево по мере прокрутки. Без прокрутки текст неподвижен. После строки появляется Валерий Иванович Лыков по центру, без пустой второй колонки. Наведение отталкивает частицы локально вокруг курсора; постоянное вращение объекта сохраняется.

Реализована единичная строка GSAP ScrollTrigger pin/scrub, без автоповторов и кнопки паузы. Статическая версия целиком переносится при reduced motion и без JS. Портрет и подписи расположены компактным центральным блоком. Shader использует положение курсора в NDC и корректирует радиус отталкивания с учётом aspect ratio. Поздний import подхватывает последнее положение курсора.

Браузер выявил конфликт порядка расчёта pin-сцен: поздно созданная верхняя сцена сдвигала нижние. Верхней сцене назначен refreshPriority:10, перед повторным расчётом выполняется sort. Тест подтверждает реальную видимость портрета после строки и доступ к CTA без перекрытия.

Проверки: hero-marquee, hero-sequence, scroll-motion, history-rendering, design-smoke. Проверены поворот матрицы WebGL, cursor uniform, пустой старт, зависимость x от scroll, неподвижность без scroll, центрирование/видимость фото, CTA, оба эксперта, mobile/reduced/no-JS, BFCache.

Изолированная холодная загрузка на телефоне, CPU×4, 200 KB/s, 150 ms: LCP 2200 ms, CLS 0, blocking 107 ms, tap 96 ms, frame p95 16.8 ms, scroll stalls 0.
