# Движение по видеореференсу

Просмотрены кадры IMG_7532.MOV (16 секунд): горизонтальная строка GSAP с непрерывным ходом, сборкой букв и разными форматами акцентных слов. По дополнительному указанию пользователя слова получают разные форматы и способы появления.

Одна фраза движется справа налево по скроллу; linear travel, scrub 0.9, без принудительных остановок. Длина сцены ограничена 7400 px desktop / 4400 px mobile. «Три дня» — более жирная жёлтая плашка с подъёмом букв; имя — голубая плашка, имя/отчество меньше над фамилией, буквы разворачиваются; профессия — курсив с увеличением; степень — контурная капсула с мягким проявлением. Доступный текст сохраняется одной полной фразой. Reduced motion и отсутствие JS дают исходное статическое содержание.

Радиус взаимодействия частиц уменьшен с 0.13 до 0.06 в нормализованных экранных координатах. Вместо радиального выталкивания используется небольшой поворот локального вектора. Это сохраняет расстояние частиц до курсора и не создаёт пустой белый круг или кольцо. Цвет и непрерывное вращение модели сохранены.

Для букв нет отдельных GSAP tween: один tween строки обновляет только изменившиеся символы, используя кеш координат. Измерения после refresh объединяются в один RAF. Убран дублирующий fonts-refresh: общий runtime уже выполняет его; приоритет вводной сцены задаётся через sort до fonts-microtask. Это устранило длинную начальную задачу (первая проверка: blocking 361 ms; итоговая: 158 ms).

GPU-проверка реального vertex shader: радиальная ошибка менее 1e-6, движение вне радиуса равно нулю, максимальное локальное смещение 0.00467. Мобильный бюджет CPU×4 / 200 KB/s / 150 ms: LCP 2444 ms, CLS 0, blocking 158 ms, tap 120 ms, frame p95 16.8 ms, stalls 0. Исходники просмотрены ревьюером; замечаний не выявлено.
